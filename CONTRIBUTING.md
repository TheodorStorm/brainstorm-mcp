# Contributing to Brainstorm MCP

Brainstorm is archived and no longer accepts contributions. It has been superseded by [Borg MCP](https://borgmcp.ai); direct new feature work, bug reports, and documentation improvements there.

This repository remains public for historical reference. Existing forks may continue under the terms in `LICENSE`.

## Security

Brainstorm is unsupported and will not receive security fixes. Do not use it for production or with untrusted agents. Report vulnerabilities in Borg MCP through the security process documented by that project.
